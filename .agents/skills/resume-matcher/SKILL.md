# Resume Matcher & Builder Skill

Use this skill when tailoring, improving, or building resumes for tech and product roles.

## Core Rules
1. **Never Invent Credentials or Numbers:** Ground every claim in the user's master resume.
2. **Outcome-Driven Bullets:** Enforce the Google XYZ formula ("Accomplished [X] as measured by [Y], by doing [Z]") and the PM TAR formula.
3. **1-Line Context:** Add a company context line under each role detailing company stage, scale, and owned scope.
4. **ATS Standards:** Single-column layout, standard headers, verified keywords.
