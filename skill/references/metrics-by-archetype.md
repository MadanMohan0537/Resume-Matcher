# Metrics by Role & Archetype

The #1 reason tech and product resumes get rejected is **missing or irrelevant metrics**. Every role has standard key performance indicators that hiring managers look for.

---

## 1. Product Manager Archetypes

### Growth & Acquisition PM
- **Key Metrics:** Sign-up conversion rate, CAC (Customer Acquisition Cost), Payback period, Referral rate, Viral coefficient (k-factor), Landing page drop-off, Onboarding completion rate.
- **Example:** *"Reduced CAC 32% while increasing organic viral invites 2.4x by introducing a collaborative workspace invite mechanic."*

### Core & Feature PM
- **Key Metrics:** DAU/MAU ratio, Feature adoption rate, CSAT, NPS, Task completion time, D1/D7/D30 retention, Churn rate.
- **Example:** *"Increased 30-day retention by 8.5 percentage points by redesigning core search filters based on 40 user interview sessions."*

### Platform & Technical PM
- **Key Metrics:** Developer velocity, API latency (p95/p99), System uptime/SLA, Infrastructure cost per query, Internal tool adoption, API error rates.
- **Example:** *"Consolidated 6 fragmented authentication services into a unified OAuth2 platform, reducing developer onboarding time from 3 weeks to 2 days."*

### AI & ML Product Manager
- **Key Metrics:** Model accuracy/F1 score, Hallucination/Eval error rate, Token latency (Time To First Token), Cost per million tokens, User acceptance of AI suggestions, Fallback rate.
- **Example:** *"Launched conversational agent handling 45% of tier-1 support queries with a 92% CSAT rating, cutting external vendor costs $450K annually."*

### Monetization & Pricing PM
- **Key Metrics:** ARR / MRR, Net Revenue Retention (NRR), Average Revenue Per User (ARPU), Free-to-paid conversion, LTV/CAC ratio.
- **Example:** *"Redesigned pricing tiers from seat-based to usage-based billing, lifting expansion revenue 28% and increasing NRR to 118%."*

## 2. Software Engineering Archetypes

### Frontend / Fullstack Engineer
- **Key Metrics:** Core Web Vitals (LCP, FID/INP, CLS), Bundle size reduction, Test coverage %, Page load time, Time to Interactive (TTI).
- **Example:** *"Decreased Largest Contentful Paint (LCP) from 3.8s to 1.1s across mobile web, directly contributing to a 6.2% lift in e-commerce checkout completion."*

### Backend & Distributed Systems Engineer
- **Key Metrics:** Requests per second (RPS), p99 latency, Database query optimization, MTTR (Mean Time to Resolution), Cloud infrastructure spend reduction.
- **Example:** *"Optimized Postgres indexing and introduced Redis read-through caching, reducing database CPU utilization 45% under 100K peak RPS."*

### AI / Machine Learning Engineer
- **Key Metrics:** Inference throughput, Model quantization savings, Training convergence time, Precision/Recall, Vector search recall rate.
- **Example:** *"Fine-tuned and quantized an 8B parameter open-source LLM using LoRA/vLLM, matching proprietary model accuracy while cutting inference latency 60%."*
