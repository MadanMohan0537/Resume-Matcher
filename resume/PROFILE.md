# Profile — voice, constraints, and guardrails

Fill this in so every tailored resume sounds like you and never overclaims. The agent must honor this file.

## Voice

- Implied first person. No "I", no "we" unless the master resume already uses it.
- Direct, specific, no buzzword stuffing. Prefer plain verbs: built, shipped, reduced, owned, designed, migrated.
- Mirror JD keywords only when they match real experience in `resume/MASTER.md`.

## Length

- Default: one page (early / mid career).
- Two pages only if the master resume is already that long or the user asks.
- Typical target: 3–5 bullets on the most recent role, 2–3 on older roles.
